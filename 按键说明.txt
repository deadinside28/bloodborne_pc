  血源诅咒 PC(Windows 移植版)按键说明
  版本: 0.6 (merge-0.6) · 2026-10-20
  键鼠和手柄可以同时使用,随时切换
════════════════════════════════════════════════════════════════════

  一句话上手:左键砍、右键枪、Shift 闪(长按跑)、空格摸、Q 喝血、C 锁定

  本机是亚版(CUSA03023),✕/○ 和欧版相反(已实测):
    ✕ = 闪避(轻点)/冲刺(长按)· 菜单取消 → 左Shift
    ○ = 互动(开门/拾取/对话)· 菜单确认 → 空格
  0.6 新引擎:按键走路自带"轻推摇杆"手感(方向渐变、斜向不超速)

【移动 / 视角】────────────────────────────
  W / A / S / D      走路(模拟爬坡:轻按=小步,长按=迈开)
  左Ctrl(按住)      慢走:无声、不惊动敌人,背刺用(35% 推杆)
  方向键 ↑↓←→        转视角
  鼠标移动           转视角(先进游戏画面点一下捕获鼠标)
  F1                 释放鼠标(切出去干别的事)
  C 或 鼠标中键      锁定 / 解锁敌人

【战斗】──────────────────────────────────
  鼠标左键 或 3       轻攻击
  鼠标右键 或 R       枪击(左手武器,枪反)
  F 或 鼠标侧键前     重攻击(按住 = 蓄力)
  1 或 鼠标侧键后     武器变形;攻击中按 = 变形攻击
  左Shift(轻点)     闪避翻滚
  左Shift(长按)     冲刺跑;跑动中松开再按一下 = 跳跃
  Q                  直接喝血瓶(不占快捷栏)

【道具 / 互动】────────────────────────────
  空格               互动(开门、拾取、对话)
  E                  使用当前快捷栏道具(可常驻血瓶)
  K 或 滚轮 ↓        切换快捷栏道具
  I 或 滚轮 ↑        造血子弹(+5 发,消耗自己 HP!战斗中慎按)
  J / L              切换左手 / 右手武器

【菜单(回车打开暂停菜单)】────────────────
  空格 / 左Shift      确认 / 取消(亚版习惯)
  I / K(或滚轮)     列表上下
  J / L              分类左右
  1 / 3              大标签页左右(手持物 ↔ 装备 ↔ 系统)
  Tab                手势菜单(触摸板左半)
  Backspace          个人效果菜单(触摸板右半,少用)

【系统】──────────────────────────────────
  Insert(或手柄 L3+R3) 移植设置菜单(画质/超分/全屏/特效;0.6 支持即时切换)
  F3                 30 FPS 上限开关(0.6 新)
  Z                  L3(基本用不到)

【鼠标详情】────────────────────────────────
  · 捕获后: 左键=轻攻击 · 右键=枪击 · 中键=锁定
    侧键前=重攻击 · 侧键后=武器变形 · 滚轮=十字键上/下
  · F1 或切出窗口 → 释放鼠标
  · 灵敏度: bbport.ini mouse_sensitivity=(现设 2)

【本机 bbport.ini 要点(亚版实测)】──────────
  dodge_button=cross    闪避/冲刺键驱动 ✕(亚版);欧版用 circle
  key.dodge/sprint=left shift   Shift=闪避/冲刺/跳跃
  key.circle=space      空格=○(互动/确认)
  战斗键: r1=3/左键 · r2=F/侧键前 · l1=1/侧键后 · l2=R/右键
  慢走默认左Ctrl 35%(walk_key / walk_percent 可改)
  ⚠ 多词键名中间必须有空格: left shift / left ctrl(写成 leftshift 会静默失效)

【手柄】──────────────────────────────────
  直接支持;从 Steam 添加 "Bloodborne PC.exe" 启动可补全 L3/R3
